# ستوديو القوالب — React Themes Studio ✦

نظام عضوية كامل + استوديو لتصميم قوالب وثيمات **React** بواجهة سحب وإفلات عربية (RTL)، مع **30 ثيماً جاهزاً**، تحكماً كاملاً بكل مكوّن (ألوان، حواف، أيقونات، حقول، حركات)، وتصديراً فورياً إلى **صفحة HTML مستقلة** أو **حزمة React (TSX)**.

| الطبقة | التقنيات |
|---|---|
| الواجهة | React 18 · TypeScript · Vite 5 · Tailwind CSS 3 |
| الخادم | PHP 8 (REST API) · SQLite (PDO) |
| الأيقونات | Lucide — أكثر من 1700 أيقونة ببحث فوري |

---

## ▲ التشغيل السريع (خادم واحد لكل شيء)

```bash
# يتطلب PHP 8.1+ (pdo_sqlite مضمّنة افتراضياً في أغلب التوزيعات)
./server/start.sh          # أو: php -S 0.0.0.0:8080 server/router.php
```

ثم افتح `http://localhost:8080` — يقدّم الخادم الواجهة المبنية (`dist/`) وواجهة API معاً، وتنشأ قاعدة SQLite تلقائياً في `server/data/app.sqlite` مع بذر الثيمات الثلاثين.

### حسابات جاهزة
| الدور | اسم المستخدم | كلمة المرور |
|---|---|---|
| **مدير** | `admin` | `admin123` |
| عضو تجريبي | `demo` | `demo123` |

## ▲ وضع التطوير (Vite + PHP)

```bash
npm install
php -S 0.0.0.0:8080 server/router.php   # نافذة أولى — الـ API
npm run dev                             # نافذة ثانية — vite على 5173 مع proxy لـ /api
```

## ▲ المزايا

- **نظام عضوية**: تسجيل/دخول برموز Bearer، جلسات 30 يوماً، حظر الأعضاء، أدوار (admin/user).
- **30 ثيماً جاهزاً** في 6 فئات (لوحات تحكم، مواقع تعريفية، تطبيقات جوال، متاجر، مدونات، محافظ أعمال) — بمعاينات حية مصغّرة.
- **محرر كامل**:
  - تخصيص مباشر: 9 ألوان، وضع فاتح/داكن، خطوط (Cairo/Tajawal/…)، حواف (مربع/دائري/كبسولة + مخصص)، ظلال، كثافة، تأثير زجاجي، تدرجات.
  - **قوائم ديناميكية متخصصة لكل مكوّن** (20 نوعاً: شريط علوي، قائمة جانبية، شريط تبويب سفلي، Hero، بطاقات، نموذج، جدول، تبويبات، باقات، آراء، معرض، قائمة، CTA، تذييل، بحث، ملف شخصي، تنبيه، أزرار، نص، إحصائيات).
  - **تغيير شكل الحقول والأزرار**独立: حواف دائرية/مربعة/كبسولة، نمط محدد/معبأ/تسطير، موضع التسمية (أعلى/بجانب/عائمة)، حواف خاصة لكل حقل.
  - **منتقي أيقونات ديناميكي** لكل عنصر (1700+ أيقونة مع بحث).
  - **سحب وإفلات**: نقل أي مكوّن بين الأقسام، إضافة شريط علوي/قائمة جانبية (يمين أو يسار)/شريط تبويب سفلي.
  - **حركات لكل عنصر**: 20 حركة (تلاشي، انزلاق، تكبير، ارتداد، قلب، دوران، نبض، طفو…) × 3 مشغّلات (تحميل/تمرير/مرور) × تحكم بالمدة والتأخير ومنحنى السرعة والتكرار.
  - تراجع/إعادة (Ctrl+Z / Ctrl+Shift+Z)، حفظ (Ctrl+S)، معاينة تفاعلية بأحجام الأجهزة (حاسوب/لوحي/جوال).
- **التصدير**:
  - `index.html` واحد مكتفٍ ذاتياً (CSS + JS مضمّنان، متجاوب، تفاعلات كاملة).
  - مشروع HTML مفصول (ZIP: index.html + assets/style.css + assets/script.js).
  - **حزمة React** (ZIP: TemplateApp.tsx + template.css + interactions.ts + theme.json + README).
- **لوحة إدارة**: إحصائيات، إدارة المستخدمين (دور/حظر/حذف)، القوالب (تمييز/حذف/معاينة)، والثيمات (إعادة تسمية/إخفاء/حذف/استعادة الافتراضي).
- **وضع التجربة دون خادم**: إذا لم يكن PHP مشغلاً يعمل التطبيق تلقائياً بتخزين محلي (بدون فقدان وظيفة التصميم والتصدير).

## ▲ واجهة الـ API (REST)

| Method | Path | الوصف |
|---|---|---|
| POST | `/api/auth/register` | عضوية جديدة `{name, username, email, password}` |
| POST | `/api/auth/login` | دخول `{identifier, password}` → `{token, user}` |
| POST | `/api/auth/logout` | إنهاء الجلسة |
| GET | `/api/auth/me` | بياناتي |
| PUT | `/api/auth/profile` | تعديل الاسم |
| GET | `/api/themes` | الثيمات المنشورة (`?all=1` للمدير) |
| GET/POST | `/api/templates` | قوالب العضو / إنشاء قالب |
| GET/PUT/DELETE | `/api/templates/{id}` | قراءة / تحديث / حذف |
| GET | `/api/admin/stats` | إحصائيات (مدير) |
| GET | `/api/admin/users` | المستخدمون (مدير) |
| PUT/DELETE | `/api/admin/users/{id}` | تعديل دور/حالة — حذف (مدير) |
| GET | `/api/admin/templates` | كل القوالب (مدير) |
| PUT/DELETE | `/api/admin/templates/{id}` | تمييز / حذف (مدير) |
| POST | `/api/admin/themes` | إنشاء/تعديل ثيم (مدير) |
| DELETE | `/api/admin/themes/{id}` | حذف ثيم (مدير) |
| POST | `/api/admin/themes/reset` | استعادة الثيمات الافتراضية (مدير) |

الترميز: `Authorization: Bearer <token>` — الردود JSON.

## ▲ بنية المشروع

```
├── dist/                    # الواجهة المبنية (تُقدَّم عبر خادم PHP)
├── server/                  # خادم PHP + SQLite
│   ├── router.php           # مدخل الخادم المدمج (API + ملفات + SPA)
│   ├── bootstrap.php        # جسر المتغيرات الفائقة → handle_api()
│   ├── api.php              # كل مسارات الـ API
│   ├── db.php               # PDO + الترحيلات + البذر
│   ├── bridge-run.php       # تشغيل نفس الكود في بيئة المعاينة (PHP-WASM)
│   ├── seed/themes.seed.json# بذور الثيمات الثلاثين (تُولَّد من TS)
│   └── data/app.sqlite      # القاعدة (تُنشأ تلقائياً — خارج Git)
├── src/
│   ├── lib/                 # الأنواع، الثيمات الـ30، الأيقونات، الحركات، التصدير
│   ├── renderer/            # مُصيّر القوالب (React) + مولّد CSS
│   ├── builder/             # لوحات المحرر (الطبقات، المفتش، الثيم، التصدير)
│   ├── pages/               # الهبوط، الدخول، الاستوديو، المحرر، الإدارة
│   └── store/ components/   # المصادقة + صندوق الواجهة
└── scripts/                 # توليد البذور + اختبارات الدخان
```

## ▲ أوامر مفيدة

```bash
npm run build     # بناء الواجهة إلى dist/
npm run seed      # إعادة توليد server/seed/themes.seed.json من تعريفات TS
npm run serve     # php -S 0.0.0.0:8080 server/router.php
```
